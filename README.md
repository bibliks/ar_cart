# Soft Mind AR-карта

WebAR-демо для iPhone: Safari распознаёт изображение `marker.png`, после чего поверх маркера появляется 3D-персонаж с лёгкой idle-анимацией.

## Проверить

1. Положите распечатанный `marker.png` горизонтально на стол или откройте его на лежащем горизонтально втором устройстве.
2. На iPhone откройте <https://bibliks.github.io/ar_cart/> в Safari.
3. Нажмите **«Запустить AR»** и разрешите доступ к камере.
4. Наведите камеру на маркер под углом. Держите его целиком в кадре и избегайте бликов — персонаж будет стоять на его плоскости, а окружение останется видно через камеру.

Камере требуется HTTPS, поэтому опубликованная версия работает через GitHub Pages. Для локальной проверки страницу нужно открывать через HTTP-сервер, а не как файл.

## Файлы

- `index.html` — интерфейс, AR-сцена и процедурная анимация;
- `character.glb` — 3D-персонаж;
- `marker.png` — изображение для распознавания;
- `card.mind` — скомпилированные признаки маркера для MindAR.

Модель содержит риг, но не содержит готовых анимационных клипов. Поэтому текущая idle-анимация создаётся кодом: персонаж плавно покачивается, поворачивает голову и двигает рукой.
